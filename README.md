# AI Resume Screening System 🚀

A modern AI-powered Resume Screening System built using Flask and Python that analyzes resumes, extracts skills, compares them with job descriptions, calculates match scores, and identifies missing skills.

---

## 📌 Features

- 📄 Upload Resume PDF
- 🧠 Automatic Skill Extraction
- 📊 Resume Match Score Calculation
- ❌ Missing Skills Detection
- 🎨 Modern Professional UI
- ⚡ Real-time Resume Analysis

---

## 🛠 Technologies Used

- Python
- Flask
- HTML
- CSS
- PyPDF2

---

## 🚀 How It Works

1. Upload a Resume PDF
2. Paste the Job Description
3. System extracts resume skills
4. Compares with required job skills
5. Generates:
   - Match Score
   - Detected Skills
   - Missing Skills
